# WindowSwitch app icon

Generated with the built-in imagegen tool. Production raster (1024 × 1024, normalized by macOS sips): `Design/AppIcon.png`; packaged macOS icon: `Sources/App/Resources/AppIcon.icns`. The iconset sizes are prepared with macOS `sips` and `iconutil`.

## Initial prompt

Use case: logo-brand. Asset type: production macOS application icon for WindowSwitch, a fast native window switcher. Create one beautifully polished, premium, immediately recognizable app icon, square 1024x1024 composition. A restrained sculptural emblem of two overlapping rounded window frames, offset diagonally, with translucent liquid glass, pearl-white beveled edges and the macOS system blue accent showing through their overlap. Put the emblem on a softly lit macOS rounded-square backplate, with genuine transparent pixels outside the backplate. Keep the emblem broad, geometrically clear and readable at 16px; generous balanced padding, front-facing, orthogonal, very subtle depth and soft contact shadows. Contemporary Apple-native material craft, calm and precise, no excessive neon, no noisy gradients, no tiny UI details. No text, letters, numbers, app names, watermarks, mockup scene, or surrounding presentation. Deliver only the finished icon asset on transparency.

## Selected refinement

Refine this macOS app icon into a final production asset. Preserve the exact two overlapping rounded window shapes, their offset, proportions, central alignment, glass depth and pearl-white frame highlights. Change only the large rounded-square backplate to a rich, restrained macOS system-blue/cobalt glass so the outside silhouette has strong clean separation. The backplate must have a perfectly smooth continuous superellipse edge, with no outer glow or external shadow. Remove ALL stray white or colored flecks and all noisy pixels outside the backplate: every pixel outside its crisp anti-aliased silhouette must be truly transparent. Do not add text, symbols, arrows, tiny details or a presentation background. One polished square application icon, readable at small sizes.

## Edge refinement

Built-in imagegen edit: preserve the two overlapping glass windows; use a single cobalt-blue backplate; remove the outer gray/white rim, glow, and stray exterior pixels; keep a genuinely transparent background. Native AppKit/Core Animation icon packaging normalizes the result to a 1024-pixel canvas with an 824-pixel plate and the system continuous corner curve. Every iconset size is regenerated from that canonical PNG; no earlier framed bitmap is used.
